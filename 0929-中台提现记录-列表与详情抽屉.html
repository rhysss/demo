📌 本次优化说明（原型标注，上线无此区块）

调整字段 / 功能原因
删除列表「用户ID」「ID」用户ID 与 UID 值完全相同；ID 为内部主键，放进抽屉
合并「内部提现 是/否」→「类型：链上提现 / 站内转账」；筛选项同步“是/否”语义不直观
合并用户ID / UID / 邮箱 / 手机 与 付款方UID / 邮箱 / 手机 → 统一为「付款方」站内转账时两组值完全重复；链上提现时付款方即发起人
合并「接收地址/用户」+ 链名称 + 网络 + 收款方UID →「接收方」一列链上显示地址+链/网络，站内显示收款方UID；ETH/Ethereum 两列冗余
移入抽屉付款方/收款方邮箱与手机号、付款腿/收款腿、是否机审、审核时间、发送次数/时间/失败原因、交易哈希、区块高度列表只留定位与判断字段，明细在抽屉看
改名「发送数量」→「到账数量」；「流水号」「订单号」统一叫「订单号」；「提现时间」→「创建时间」筛选项叫订单号、列表叫流水号，口径不一致
改口径付款腿/收款腿去掉红色「缺失」，改成 已冻结 / 待入账 / 已扣款 / 已入账 / 已解冻退回 / 不入账待审核时显示「缺失」像是出了故障；按「提交即冻结」规则显示
修数据站内转账的发送状态/次数/区块高度显示「—」；未审核的审核时间显示「—」；「已取消 + 未通过」改为「已拒绝」现网站内转账显示「提现成功 + 未发送 + 区块高度 0」，自相矛盾；未审核的单子也有审核时间
新增状态快捷 Tab（含待审核计数）、审核人、审核备注、完成时间、留言（站内）、审核方式筛选审核需要留痕；审核员主要处理「待审核」队列
新增损益里加「站内转入 / 站内转出」统计 ⚠️ 口径待确认现在入金只统计站外充值，拿站内转账进来的钱去提现，风控看不到钱的来源
交互点整行或「详情」都能打开抽屉，任何状态都能打开；审核统一在抽屉底部（去掉原来的站内转账审核弹窗）审核站内转账时也要看损益
