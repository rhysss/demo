PNL 分析 · 竞品口径调研 & 通用规则

对标 OKX / Bitget / Bybit / Gate（币安作基准），拉齐字段口径 → 输出统一规则 → 新功能与交互建议
整理日期：2026-07-22 ｜ 素材：各家 App「盈亏/收益分析」页 & 指标说明弹窗 ｜ 用途：PNL 需求评审前置调研

一句话结论：各家的盈亏定义"形似神不同"。核心分歧不在展示，而在三件事——①用总资产还是钱包余额作基准（决定含不含未实现盈亏）；②时区/日切（UTC+0 还是 UTC+8）；③净流水怎么算（净转入 vs 净充值+净提币）。把这三件事定死，其余公式基本可统一。同事说的"没想象那么简单"正是卡在这里。

二、通用规则建议（可落地口径）

把分歧收敛为两套口径 + 一组统一边界。所有指标按"场景"选口径，不再逐指标各自定义。

🅰 资产口径（Mark-to-Market）

基于总资产/总估值，天然包含未实现盈亏。用于「资产报告 / 总资产今日盈亏 / 累计盈亏(资产)」。

盈亏 = 当前资产 − 期初资产 − 期间净流水

🅱 钱包口径（Realized/Cash）

基于钱包余额/已平仓，不含未实现盈亏。用于「合约每日盈亏 / 合约累计盈亏 / 交易分析」。

盈亏 = 期末钱包 − 期初钱包 − 期间净流水

统一约定（两套口径共用）

  • 净流水 = 净转入 − 净转出（= 充值+划入 − 提现+划出），符号统一用"净转入"表达。
  • 时区/日切：全线 UTC+0 每日 00:00 切日（含自定义时间控件与图表日期）。杜绝 Gate 式 UTC+8/UTC+0 混用。
  • 维护窗口：每日 0:00–4:00 (UTC) 数据维护，期间不计算/可能延迟，页面显式标注。
  • 累计盈亏率 = 累计盈亏 ÷ (期初资产 + 期间日均净转入)；分母 ≤ 0 或初始为 0 时显示 N/A / 仅显额不显率。
  • 手续费/资金费：合约平仓总盈亏默认计入开平仓手续费与资金费用，并提供「展示手续费」开关切换显隐。
  • 排除项：交易机器人、跟单产生的交易量/盈亏不计入统计（或单列）。
  • 起算基线：定一个明确起算时间（如账户创建或某固定日）并在"累计/历史盈亏"弹窗标注。
  • 精度：金额/百分比统一 2 位、截断（已在原型落地）。

三、竞品新功能 · 是否引入建议

建议加
交易分析质量指标：胜率、盈亏比、风险回报比、仓位数、多空比、平均持仓时间、最大收益/最大亏损、平均盈亏。
来源：Gate/Bitget/OKX ｜ 理由：这是"交易者"最想看的核心，竞品普遍标配，我方目前完全缺失。
建议加
盈亏排名（按合约/币种，按绝对值从大到小）。
来源：OKX/Bitget ｜ 理由：快速定位盈亏来源，低成本高价值。
建议加
平仓订单 / 平仓仓位 明细 + 单笔详情（入场/出场价、开平仓量、开平仓手续费、资金费用、成交类型、持仓周期）。
来源：OKX/Bybit ｜ Bybit 的 K线标注开平仓点 + Win 徽章 体验很亮眼，值得借鉴。
建议加
BTC 对比基准线（累计盈亏率 vs BTC 涨跌）。
来源：Gate/Bitget/OKX ｜ 理由：极低成本，帮助用户判断"跑赢/跑输大盘"。
建议加
收益额 / 收益率 / 资产走势 三视图切换 + $/% 切换。
来源：Gate/OKX ｜ 理由：同一区域承载多维度，信息密度高。
建议加
日历点选 tooltip 增强：显示 单日盈亏/已实现/未实现/其他盈亏/净划转/交易量。
来源：Bitget/OKX ｜ 我方日历目前只显数字、无点选详情。
建议加
展示手续费开关 + 数据更新时间/维护提示。
来源：Gate/OKX ｜ 口径透明度，减少客诉。

四、当前原型缺失的交互（待补清单）

原型已有：时间切换联动、折线落点可拖动 scrub、日历月份切换 + 0值填充、饼图/折线切换、标题下拉切换页面、自定义日期弹层、图表收起。
对比竞品还缺：

P0指标 ⓘ 口径说明弹窗——每个指标（今日盈亏/累计盈亏/累计盈亏率/总盈利…）点 ⓘ 弹出公式说明。竞品全都有，我方全无。最高优先
P0日历日期点选 tooltip——点某天弹出该日多维盈亏明细（对齐第三节增强项）。
P0交易分析指标区——新增胜率/盈亏比/最大收益亏损/多空比/平均持仓等（内容+交互）。
P1柱状图落点/点选 tooltip——单日盈亏柱状图支持点选查看当日详情。
P1盈亏排名 + 平仓明细列表——列表 + 单笔详情。
P1收益额/收益率/资产走势 三切换 + BTC 对比线 + $/% 切换。
P2账户/币种/合约 筛选器（顶部下拉）。
P2展示手续费开关 & 数据更新时间/维护提示。

建议下一步（供你拍板）

先落 P0 三项到原型（指标 ⓘ 弹窗 + 日历点选 tooltip + 交易分析指标区）——它们最贴合"PNL 分析"评审、且改造量可控。P1/P2 再排后续迭代。
