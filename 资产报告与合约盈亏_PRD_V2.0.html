背景需求

平台现有「资产」模块仅展示静态余额，用户无法回看资产变化趋势与合约盈亏表现，缺少一个体检式的数据分析入口。本次从 0 到 1 新增两个分析页——总资产分析（账户级）与合约盈亏分析（合约账户级），把资产走势、每日盈亏、累计盈亏率（对比 BTC）、资产构成、交易表现与逐笔订单整合到一起。核心目标是提升资产页停留时长与合约复访率，并为后续「跟单 / 策略」增值功能沉淀数据入口。

    • 资产口径（总资产分析 / 资产总览等账户级，今日 / 本月 / 累计 / 近 N 天）：盈亏 = 账户权益变化，含未实现盈亏；持仓浮动盈亏当日即计入盈亏（权益 = 各钱包余额 + 未实现盈亏）。
    • 合约账户口径（合约盈亏分析页，今日 / 本月 / 累计 / 每日）：盈亏 = 钱包余额变化 = 已实现（平仓盈亏 + 资金费用 − 交易手续费），不含未实现盈亏；持仓浮盈浮亏在平仓当日才转为已实现计入，未平仓期间不进盈亏。
    未实现盈亏仅体现在「合约账户估值（权益）= 钱包余额 + 未实现盈亏」与「未实现盈亏」指标本身，其余盈亏指标不再逐一标注。

总资产分析

原型需求说明
见原型 · 总资产分析

1、入口

  • 资产·总览页，点击「今日盈亏 · 资产报告」行进入
  • 合约盈亏分析页，点击标题下拉切换进入

2、概览图表（位于盈亏概览头部下方）

  • 双视图切换：折线图标 = 资产走势、环形图标 = 资产分布，左上角图标切换
  • 资产走势（折线）：可选周期 1天 / 7天 / 30天 / 180天 / 360天，展示总资产估值走势
    粒度：1天=10分钟 · 7天=30分钟 · 30天=1小时 · 180天/360天=按天（分钟点位对齐 10/30/60）
    更新节点（各筛选刷新频率）：1天 每10分钟 · 7天 每30分钟 · 30天 每1小时 · 180天/360天 按天（每日 24:00 收盘刷新，最新一日取实时估值）
    每日取值：按天粒度取当日 24:00(= 次日 00:00 UTC+8) 收盘值（当日最后一个快照，最新一日取实时估值）
  • 默认全量：折线默认展示整段实线，不显示落点 / 竖虚线 / 时间标签，顶部「总资产估值」为当前值
  • 落点交互：手指拖动折线才出现竖虚线落点，时间标签展示在竖虚线顶部；落点资产估值联动展示在顶部「总资产估值」处（无黑色数值气泡）；松开手指恢复默认全量状态
    时间格式：1天「时:分」· 7天/30天「月/日 时:分」· 180天/360天「月/日」
  • 最高 / 最低标注：折线上标出所选周期内的最高、最低资产估值——仅标数值，不打落点
  • 切换周期联动：切换下方时间时，「今日盈亏」区块同步展示所选区间盈亏（如选 7天 → 近7天盈亏及金额）；涨跌幅胶囊紧跟盈亏金额后（红跌绿涨）
  • 口径说明弹窗：盈亏标签（今日盈亏 / 近7天 / 近30天 / 近180天 / 近360天）带虚线下划线，点击弹出对应口径；点击标签不跳转（阻止冒泡），点击行其余区域进入资产报告
    盈亏率 = 盈亏 ÷ 期初资产 × 100%（期初资产 = 该周期起点当日 00:00 的资产）
  • 资产分布（环形）：各账户市值占比，环形 + 图例，不含负债
    占比 = 当前账户资产 ÷ 总资产
  • 展开 / 收起：chevron 图标（位于涨跌幅下方、右对齐），点击切换图表显隐，图标随展开态翻转

3、页面说明——由「盈亏概览头部、时间筛选、资产走势、盈亏统计、每日盈亏、资产配置」构成。

① 盈亏概览头部（固定，不随下方时间筛选变化）

  • 总资产估值：不含负债，随标记价格实时变化，支持「眼睛」隐藏
    总资产估值 = Σ 各账户(资金/现货/合约/理财/Launchpad)折算计价币种后的估值
  • 今日盈亏：每10分钟更新一次；今日初始 = 当日 00:00(UTC+8) 资产
    今日盈亏 = 当前资产 − 今日初始资产 − 今日净转入
    今日净转入 = 今日划入 − 今日划出
    盈亏率 = 今日盈亏 ÷ 今日初始资产 × 100%
  • 本月盈亏：本月初 = 本月第一个自然日 00:00(UTC+8) 的资产
    本月盈亏 = 当前资产 − 本月初资产 − 本月净转入
    盈亏率 = 本月盈亏 ÷ 本月初资产 × 100%
  • 累计盈亏（账户全期累计，固定，不随时间筛选变化；与下方④「盈亏统计」的区间累计不是同一口径）
    累计盈亏 = 当前资产 − 账户初始资产 − 累计净转入（账户初始 = 开户/首次入金时点资产）
    盈亏率 = 累计盈亏 ÷ (账户初始资产 + 累计净转入) × 100%

② 时间筛选（吸顶）：7天 / 30天 / 90天 / 180天 / 自定义时间；控制下方「资产走势、盈亏统计」，不控制「每日盈亏、资产配置」。

【基准口径 · 盈亏率统一分母】

期初资产(T) = 时点 T 当日 00:00(UTC+8) 的账户总资产
每日盈亏 = 当日期末资产 − 当日期初资产 − 当日净转入
单日盈亏率 = 每日盈亏 ÷ 当日期初资产 × 100%
累计盈亏 = 区间每日盈亏之和（Σ 每日盈亏）= 区间期末资产 − 区间初始资产 − 区间净转入
累计盈亏率 = 累计盈亏 ÷ (区间初始资产 + 期间净转入) × 100%；区间初始资产 = 区间第一天的当日期初资产

*一致性：区间第一天，当日期初资产 = 区间初始资产；当天无净转入时该日「单日盈亏率 = 累计盈亏率」，避免同一天两值对不上。

③ 资产走势

  • 折线图：所选周期内每日资产估值走势；每日取当日 24:00(= 次日 00:00 UTC+8) 收盘值（当日最后一个快照，最新一日取实时估值）；交互与总览概览图表一致——默认整段实线不显示落点，最高/最低仅标数值
  • 高亮框：默认展示区间末值；拖动折线才出现竖虚线落点并回填「日期 + 当日估值」，松开手指恢复默认（区间末值）

④ 盈亏统计（切换：累计盈亏 / 累计盈亏率）

  • 累计盈亏（所选区间累计，随时间筛选变化；与头部①「账户全期累计盈亏」不是同一口径——头部为账户全期固定值，此处仅统计所选区间）。走势图把区间内每日 PnL 依次累加(cumsum)串联展示，与「每日盈亏」日历同源、逐日对齐（默认全量实线，拖动才落点，松开还原，交互同总览）
    第 k 天的点 = Σ(第 1…k 天) 每日 PnL（如 day1 -1.3 → -1.3、day2 +4.3 → 3.0）；顶部高亮框 = 落点当天累计值，末点即区间总累计
    每日 PnL = 当日期末资产 − 当日期初资产 − 当日净转入
  • 累计盈亏率：叠加 BTC 累计涨跌幅对比线；分母为 0 等特殊情境显示 N/A；交互同上（口径见上方【基准口径】）
    累计盈亏率 = 累计盈亏 ÷ (区间初始资产 + 期间净转入) × 100%
    累计盈亏 = 盈亏日历上区间内各日盈亏相加（Σ 每日盈亏）；区间初始资产 = 区间第一天 00:00(UTC+8) 的资产
    BTC 累计涨跌率 = (当日期末价 − 区间初价) ÷ 区间初价 × 100%；区间初价 = 区间第一天 00:00(UTC+8) 的 BTC 价；当日期末价 = 当日 24:00（= 次日 00:00 UTC+8）的 BTC 价（与资产走势"取当日 24:00 收盘"一致）
    注：走势图第 k 天的点 = (第 k 天期末价 − 区间初价) ÷ 区间初价，分母恒为区间初价、非逐日累加（区别于用户盈亏的 cumsum）。示例（区间初价 = 7/24 0:00 = 65,099.2）：7/24 期末 64,145.9 → −1.46%；7/25 期末 64,372.0 → −1.11%（末点即最新一日）
  • 点击卡片标题 ⓘ 弹出「盈亏统计」口径（累计盈亏 + 累计盈亏率合并说明）；统计时间以 00:00(UTC+8) 为准

⑤ 每日盈亏（日历图默认 / 柱状图 双视图，图标切换）

  • 本卡为固定全量数据，不随时间筛选变化，可翻月查看
  • 每日盈亏值：指定日期账户持仓与交易活动产生的收益额；点选某日高亮并回填当日盈亏；无默认选中态
    每日盈亏 = 当日期末资产 − 当日期初资产 − 当日净转入
    单日盈亏率 = 每日盈亏 ÷ 当日期初资产 × 100%（当日期初资产 = 当日 00:00 UTC+8 账户资产）
  • 日历热力底色按盈亏幅度着色（绿盈红亏）；与「盈亏统计」累计盈亏同源、逐日对齐

⑥ 资产配置（切换：币种组成 / 资产分布）

  • 副标题：最近更新 时间(UTC+8)；本卡不随时间筛选变化
  • 币种组成：点击币种环形高亮；超 Top10 归并「其他」
    占比 = 各币种折算资产 ÷ 总资产
  • 资产分布
    占比 = 各账户资产 ÷ 总资产

Tips：未登录不展示本页；跟用户相关数据默认 --。

原型需求说明

1、入口

  • 资产·合约页，点击「今日已实现盈亏 · 合约盈亏」行进入

2、页面说明——由「盈亏概览、时间筛选、总览 Tab、合约分析 Tab」构成；右上角分享图标唤起分享海报。

分享海报（点击右上角分享图标，底部弹出）

  • 海报（品牌绿）：标题「我的合约盈亏」+ 累计盈亏率 %（大号）+ 期间（随时间筛选）+ 进度条 + 累计盈亏(USD) / 胜率 + 品牌名 / UID / 二维码；数据取当前筛选区间
  • 可选择是否分享信息：「累计盈亏(USD)」「胜率 %」两枚可勾选 chip，取消勾选则该项从海报隐藏（保护隐私）
  • 底部按钮：下载（存海报到相册）/ 分享（调起系统分享）

盈亏概览（固定头部，与总资产分析同款结构：顶部合约账户估值大号主数字 → 今日盈亏虚线小行 → 本月 / 累计双列）

未实现盈亏口径：合约账户的盈亏只算「已实现」，不算「未实现」。
• 本页所有盈亏（今日 / 本月 / 累计 / 每日）都是已实现，也就是真正落袋的钱：平仓赚亏 + 资金费 − 手续费。
• 持仓还没平时的浮动盈亏（未实现盈亏）不算进这些盈亏里，只在顶部「合约账户估值」和「未实现盈亏」两处单独看。
• 等你平仓那天，这笔浮盈 / 浮亏才变成已实现，计入当天盈亏。
  • 合约账户估值（大号主数字，右侧带计价单位 USDT ▾）：合约账户此刻值多少钱（权益快照），随标记价格实时变化。
    合约账户估值（权益）= 钱包余额 + 未实现盈亏
    钱包余额 = 总净划入 + 总已实现盈亏 + 总净资金费用 − 总手续费 待确认

    · 钱包余额：已经落袋的钱（本金进出 + 已实现盈亏 + 资金费净额 − 手续费）。
    · 未实现盈亏：当前持仓还没平的浮动盈亏，随价格变。
    · 两者相加 = 账户当前总价值（权益）。

  • 今日盈亏（估值下方虚线小行，内联 ±X USD (±X%) 单行展示，红跌绿涨）：今日初 = 当日 00:00(UTC+8) 钱包余额
    今日盈亏 = 当前钱包余额 − 今日初钱包余额 − 今日资金净转入
    今日资金净转入 = 今日划入 − 今日划出
    盈亏率 = 今日盈亏 ÷ 今日初钱包余额 × 100%
  • 本月盈亏：本月初 = 本月第一个自然日 00:00(UTC+8) 的钱包余额
    本月盈亏 = 当前钱包余额 − 本月初钱包余额 − 本月资金净转入
    盈亏率 = 本月盈亏 ÷ 本月初钱包余额 × 100%
  • 累计盈亏：
    累计盈亏 = 期末钱包余额 − 期初钱包余额 − 期间资金净转入
    盈亏率 = 累计盈亏 ÷ (期初钱包余额 + 期间资金净转入) × 100%
  • 备注：以上今日 / 本月 / 累计盈亏均以钱包余额为基准，而钱包余额本身就是已实现口径（已落袋），故这些盈亏均不含未实现盈亏，公式无需额外扣减；未实现只体现在上方「合约账户估值」。

时间筛选：7日 / 近1个月 / 近3个月 / 近1年 / 自定义。

总览 Tab（吸顶，与「合约分析」切换）

盈亏统计（切换：累计盈亏 / 累计盈亏率）

  • 累计盈亏（所选区间累计，随时间筛选变化；口径同总资产分析④，仅"资产"换成"钱包余额、已实现"）。走势图把区间内每日 PnL 依次累加(cumsum)串联展示，与「每日盈亏」日历同源、逐日对齐（默认全量实线，拖动才落点，松开还原，交互同总览）
    累计盈亏 = Σ 每日盈亏 = 区间期末钱包余额 − 区间期初钱包余额 − 区间资金净转入
    第 k 天的点 = Σ(第 1…k 天) 每日 PnL（如 day1 -1.3 → -1.3、day2 +4.3 → 3.0）；顶部高亮框 = 落点当天累计值，末点即区间总累计
    每日 PnL = 当日期末钱包余额 − 当日期初钱包余额 − 当日资金净转入
  • 累计盈亏率：叠加 BTC 累计涨跌率对比线；分母为 0 等特殊情境显示 N/A；交互同上
    累计盈亏率 = 累计盈亏 ÷ (区间期初钱包余额 + 期间资金净转入) × 100%
    累计盈亏 = 盈亏日历上区间内各日盈亏相加（Σ 每日盈亏）；区间期初钱包余额 = 区间第一天 00:00(UTC+8) 的钱包余额
    BTC 累计涨跌率 = (当日期末价 − 区间初价) ÷ 区间初价 × 100%；区间初价 = 区间第一天 00:00(UTC+8) 的 BTC 价；当日期末价 = 当日 24:00（= 次日 00:00 UTC+8）的 BTC 价（与走势"取当日 24:00 收盘"一致）
    注：走势图第 k 天的点 = (第 k 天期末价 − 区间初价) ÷ 区间初价，分母恒为区间初价、非逐日累加（区别于用户盈亏的 cumsum）。示例（区间初价 = 7/24 0:00 = 65,099.2）：7/24 期末 64,145.9 → −1.46%；7/25 期末 64,372.0 → −1.11%（末点即最新一日）

每日盈亏（日历默认 / 柱状；钱包口径已实现，不含未实现盈亏）

  • 公式（当日已落袋现金流合计）：
    每日盈亏 = 当日 24:00(= 次日 00:00 UTC+8) 钱包余额 − 当日 00:00 钱包余额 − 当日资金净转入
    = 当日平仓盈亏 + 当日资金费用 − 当日交易手续费（+ 保险清算费等）
  • 跨天边界：每日按左闭右开区间 [当日 00:00, 次日 00:00) 统计，期末快照与次日期初共用同一时点；这样恰好落在 00:00 结算的第 3 笔资金费能干净归入当天，跨天不漏算、不重复，且 Σ每日 = 累计（末−首）严格成立
  • 无操作日仍有 PnL：只要持有未平仓永续仓位，当日跨资金费结算点（每 8 小时一次）就会产生资金费用——即使当天不交易也会计入当日盈亏；只有完全空仓（无持仓）的日子每日盈亏才为 0
  • 点选某日回填当日盈亏

合约分析 Tab · 交易分析卡（基于已完全平仓仓位；含开平仓手续费与资金费用；机器人/跟单不纳入）

  • 胜率 = 盈利仓位数 ÷ 总平仓仓位数
  • 总仓位：期间平仓仓位总数
  • 总盈亏比 = 总盈利 ÷ 总亏损
  • 交易金额：期间成交额折算 USD
  • 最大收益 / 最大亏损：单笔已实现盈亏的最大正值 / 最小负值（涨跌色）
  • 总盈利 / 总亏损：期间已实现获利 / 亏损加总，下方绿红占比进度条
  • 盈利 / 亏损四项（对应顶部 总盈利 / 总亏损；每项均以进度条表达两边数据——左绿=盈利侧、右红=亏损侧，多空比则左多头、右空头；平均盈亏符号与所在侧一致，盈利为正/绿、亏损为负/红）：
    平均持仓时间 = 该类别（盈利 / 亏损）仓位持仓时长之和 ÷ 该类别仓位数（持仓时长 = 平仓时间 − 开仓时间）
    仓位数 = 盈利仓位数 / 亏损仓位数（两列合计 = 总平仓仓位数）
    多空比 = 多头仓位数 : 空头仓位数（全局指标，两列展示同一值）
    平均盈亏：盈利列 = 总盈利 ÷ 盈利仓位数（正）；亏损列 = 总亏损 ÷ 亏损仓位数（负）（均含开平仓手续费与资金费用，涨跌色）
