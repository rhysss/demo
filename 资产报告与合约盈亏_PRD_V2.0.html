背景需求

平台现有「资产」模块仅展示静态余额，用户无法回看资产变化趋势与合约盈亏表现，缺少一个体检式的数据分析入口。本次从 0 到 1 新增两个分析页——总资产分析（账户级）与合约盈亏分析（合约账户级），把资产走势、每日盈亏、累计盈亏率（对比 BTC）、资产构成、交易表现与逐笔订单整合到一起。核心目标是提升资产页停留时长与合约复访率，并为后续「跟单 / 策略」增值功能沉淀数据入口。

总资产分析

原型需求说明
见原型 · 总资产分析

1、入口

  • 资产·总览页，点击「今日盈亏 · 资产报告」行进入
  • 合约盈亏分析页，点击标题下拉切换进入

2、概览图表（位于盈亏概览头部下方）

  • 双视图切换：折线图标 = 资产走势、环形图标 = 资产分布，左上角图标切换
  • 资产走势（折线）：可选周期 1天 / 7天 / 30天 / 180天 / 360天，展示总资产估值走势
    粒度：1天=10分钟 · 7天=30分钟 · 30天=1小时 · 180天/360天=按天（分钟点位对齐 10/30/60）
    每日取值：按天粒度取当日 24:00(UTC+8) 收盘值（当日最后一个快照，最新一日取实时估值）
  • 默认全量：折线默认展示整段实线，不显示落点 / 竖虚线 / 时间标签，顶部「总资产估值」为当前值
  • 落点交互：手指拖动折线才出现竖虚线落点，时间标签展示在竖虚线顶部；落点资产估值联动展示在顶部「总资产估值」处（无黑色数值气泡）；松开手指恢复默认全量状态
    时间格式：1天「时:分」· 7天/30天「月/日 时:分」· 180天/360天「月/日」
  • 最高 / 最低标注：折线上标出所选周期内的最高、最低资产估值——仅标数值，不打落点
  • 切换周期联动：切换下方时间时，「今日盈亏」区块同步展示所选区间盈亏（如选 7天 → 近7天盈亏及金额）；涨跌幅胶囊紧跟盈亏金额后（红跌绿涨）
  • 口径说明弹窗：盈亏标签（今日盈亏 / 近7天 / 近30天 / 近180天 / 近360天）带虚线下划线，点击弹出对应口径；点击标签不跳转（阻止冒泡），点击行其余区域进入资产报告
    盈亏率 = 盈亏 ÷ 期初资产 × 100%（期初资产 = 该周期起点当日 00:00 的资产）
  • 资产分布（环形）：各账户市值占比，环形 + 图例，不含负债
    占比 = 当前账户资产 ÷ 总资产
  • 展开 / 收起：chevron 图标（位于涨跌幅下方、右对齐），点击切换图表显隐，图标随展开态翻转

3、页面说明——由「盈亏概览头部、时间筛选、资产走势、盈亏统计、每日盈亏、资产配置」构成。

① 盈亏概览头部（固定，不随下方时间筛选变化）

  • 总资产估值：不含负债，随标记价格实时变化，支持「眼睛」隐藏
    总资产估值 = Σ 各账户(资金/现货/合约/理财/Launchpad)折算计价币种后的估值
  • 今日盈亏：含未实现盈亏；每10分钟更新一次；今日初始 = 当日 00:00(UTC+8) 资产
    今日盈亏 = 当前资产 − 今日初始资产 − 今日净转入
    今日净转入 = 今日划入 − 今日划出
  • 本月盈亏：本月初 = 本月第一个自然日 00:00(UTC+8) 的资产
    本月盈亏 = 当前资产 − 本月初资产 − 本月净转入
  • 累计盈亏（账户全期累计，固定，不随时间筛选变化；与下方④「盈亏统计」的区间累计不是同一口径）：含已实现 + 未实现盈亏
    累计盈亏 = 当前资产 − 账户初始资产 − 累计净转入（账户初始 = 开户/首次入金时点资产）

② 时间筛选（吸顶）：7天 / 30天 / 90天 / 180天 / 自定义时间；控制下方「资产走势、盈亏统计」，不控制「每日盈亏、资产配置」。

【基准口径 · 盈亏率统一分母】

期初资产(T) = 时点 T 当日 00:00(UTC+8) 的账户总资产（含各钱包未实现盈亏）
每日盈亏 = 当日期末资产 − 当日期初资产 − 当日净转入
单日盈亏率 = 每日盈亏 ÷ 当日期初资产 × 100%
累计盈亏 = 区间每日盈亏之和（Σ 每日盈亏）= 区间期末资产 − 区间初始资产 − 区间净转入
累计盈亏率 = 累计盈亏 ÷ (区间初始资产 + 期间净转入) × 100%；区间初始资产 = 区间第一天的当日期初资产

*一致性：区间第一天，当日期初资产 = 区间初始资产；当天无净转入时该日「单日盈亏率 = 累计盈亏率」，避免同一天两值对不上。

③ 资产走势

  • 折线图：所选周期内每日资产估值走势；每日取当日 24:00(UTC+8) 收盘值（当日最后一个快照，最新一日取实时估值）；交互与总览概览图表一致——默认整段实线不显示落点，最高/最低仅标数值
  • 高亮框：默认展示区间末值；拖动折线才出现竖虚线落点并回填「日期 + 当日估值」，松开手指恢复默认（区间末值）

④ 盈亏统计（切换：累计盈亏 / 累计盈亏率）

  • 累计盈亏（所选区间累计，随时间筛选变化；与头部①「账户全期累计盈亏」不是同一口径——头部为账户全期固定值，此处仅统计所选区间）：含未实现 + 已实现盈亏；走势图把区间内每日 PnL 依次累加(cumsum)串联展示，与「每日盈亏」日历同源、逐日对齐（默认全量实线，拖动才落点，松开还原，交互同总览）
    第 k 天的点 = Σ(第 1…k 天) 每日 PnL（如 day1 -1.3 → -1.3、day2 +4.3 → 3.0）；顶部高亮框 = 落点当天累计值，末点即区间总累计
    每日 PnL = 当日期末资产 − 当日期初资产 − 当日净转入
  • 累计盈亏率：叠加 BTC 累计涨跌幅对比线；分母为 0 等特殊情境显示 N/A；交互同上（口径见上方【基准口径】）
    累计盈亏率 = 累计盈亏 ÷ (区间初始资产 + 期间净转入) × 100%
    累计盈亏 = 盈亏日历上区间内各日盈亏相加（Σ 每日盈亏）；区间初始资产 = 区间第一天 00:00(UTC+8) 的资产
    BTC 累计涨跌率 = (当前 BTC 价 − 区间初始 BTC 价) ÷ 区间初始 BTC 价 × 100%；区间初始 BTC 价 = 区间第一天 00:00(UTC+8) 的 BTC 价
    注：BTC 走势图第 k 天的点 = (第 k 天 BTC 价 − 区间初价) ÷ 区间初价，分母恒为区间初价、非逐日累加（区别于用户盈亏的 cumsum）。示例（区间初价 60,000）：07/17 价 61,200 → +2.00%；末日 07/21 价 58,800 → −2.00%（即末点）
  • 点击卡片标题 ⓘ 弹出「盈亏统计」口径（累计盈亏 + 累计盈亏率合并说明）；统计时间以 00:00(UTC+8) 为准

⑤ 每日盈亏（日历图默认 / 柱状图 双视图，图标切换）

  • 本卡为固定全量数据，不随时间筛选变化，可翻月查看
  • 每日盈亏值：指定日期账户持仓与交易活动产生的收益额；点选某日高亮并回填当日盈亏；无默认选中态
    每日盈亏 = 当日期末资产 − 当日期初资产 − 当日净转入
    单日盈亏率 = 每日盈亏 ÷ 当日期初资产 × 100%（当日期初资产 = 当日 00:00 UTC+8 账户资产）
  • 日历热力底色按盈亏幅度着色（绿盈红亏）；与「盈亏统计」累计盈亏同源、逐日对齐

⑥ 资产配置（切换：币种组成 / 资产分布）

  • 副标题：最近更新 时间(UTC+8)；本卡不随时间筛选变化
  • 币种组成：点击币种环形高亮；超 Top10 归并「其他」
    占比 = 各币种折算资产 ÷ 总资产
  • 资产分布
    占比 = 各账户资产 ÷ 总资产

Tips：未登录不展示本页；跟用户相关数据默认 --。

合约盈亏分析

原型需求说明
见原型 · 盈亏概览 + 时间筛选

1、入口

  • 资产·合约页，点击「今日已实现盈亏 · 合约盈亏」行进入
  • 总资产分析页，点击标题下拉切换进入

2、页面说明——由「盈亏概览、时间筛选、总览 Tab、合约分析 Tab」构成。

盈亏概览

  • 今日盈亏：% + USD 双展示；= 当前资产 − 今日初始资产 − 今日净转入
  • 本月盈亏：= 本月第一个自然日 00:00(UTC+8) 至当前累计盈亏
  • 累计盈亏：= 期末钱包余额 − 期初钱包余额 − 期间资金净转入（钱包口径，不含未实现）；下方附盈亏率
  • 交易额标签（右上角）：点击跳「合约分析」Tab

时间筛选：7日 / 近1个月 / 近3个月 / 近1年 / 自定义。
见原型 · 总览 Tab

总览 Tab（吸顶，与「合约分析」切换）

盈亏统计（切换：累计盈亏 / 累计盈亏率）

  • 累计盈亏：= 期末钱包余额 − 期初钱包余额 − 期间资金净转入
  • 累计盈亏率：= 累计盈亏 ÷ (期初钱包余额 + 期间日均资金总转入)；叠加 BTC 对比线；特殊情境 N/A

每日盈亏（日历默认 / 柱状）

  • = 每日 24:00(UTC+8) 钱包余额 − 每日 00:00 钱包余额 − 每日资金净转入（钱包口径，不含未实现）
  • 点选某日回填当日盈亏
见原型 · 合约分析 Tab · 交易分析

合约分析 Tab · 交易分析卡（基于已完全平仓仓位；含开平仓手续费与资金费用；机器人/跟单不纳入）

  • 胜率 = 盈利仓位数 ÷ 总平仓仓位数
  • 总仓位：期间平仓仓位总数
  • 总盈亏比 = 总盈利 ÷ 总亏损
  • 交易金额：期间成交额折算 USD
  • 最大收益 / 最大亏损：单笔已实现盈亏的最大正值 / 最小负值（涨跌色）
  • 总盈利 / 总亏损：期间已实现获利 / 亏损加总，下方绿红占比进度条
  • 多头 / 空头双列：各含 平均持仓时间、仓位数、多空比、平均盈亏（= (总盈利−总亏损) ÷ 仓位数，涨跌色）
见原型 · 合约分析 Tab · 盈亏排行 + 订单明细

盈亏排行卡

  • 按合约(如 BTCUSDT)聚合，按盈亏额绝对值从大到小 Top5；条形 + 数值（涨跌色）

订单明细卡（三 Tab，详见下节「订单明细」）：订单历史 / 交易历史 / 仓位历史。

订单明细

原型需求说明
见原型 · 订单明细 · 订单历史

1、入口：合约盈亏分析页「合约分析」Tab 下的「订单明细」卡。

2、页面说明——由「订单历史、交易历史、仓位历史」三 Tab 构成，默认订单历史。

订单历史（每张卡片，点击整卡 → 订单详情）

  • 币种：如 BTCUSDT 永续
  • 标签行：开/平·多/空 · 市价/限价 · 逐仓/全仓 · 杠杆倍数 · 委托时间
  • 价格：市价单显示「市价」，限价单显示委托价
  • 数量：成交量 / 委托量（如 0.001/0.001 BTC）
  • 状态：已成交（绿）/ 已取消（红）
见原型 · 交易历史 / 仓位历史

交易历史（逐笔成交）

  • 币种 · 永续；标签（平多/平空）+ 成交时间
  • 订单编号（可复制）、价格、数量、手续费、已实现盈亏（涨跌色）、角色（吃单/挂单）

仓位历史（逐仓位）

  • 币种 · 永续 + 跳转图标；标签（多/空 · 逐仓/全仓 · 杠杆）
  • 九宫格：开仓价 / 数量 / 已实现盈亏、平仓价 / 平仓类型(交易·强平) / ROE、开仓时间 / 平仓时间
  • ROE = 未实现盈亏 ÷ 起始保证金 × 100%（沿用平台现有口径）
