一、概述

1.1 背景与目标

背景：现有 App「资产」模块只展示静态余额，用户无法回看资产变化趋势与合约盈亏表现，缺少体检式的数据分析页。本次新增两个分析页——总资产分析（账户级）与合约盈亏分析（合约账户级），帮助用户理解「钱从哪来、赚亏多少、仓位表现如何」。

产品目标

  • 业务目标：提升资产页停留时长与合约复访率；为后续「跟单 / 策略」等增值功能提供数据入口。
  • 用户目标：一屏看清指定周期内的资产走势、每日盈亏、累计盈亏率（对比 BTC）、资产构成，以及合约的交易表现与逐笔订单历史。

1.2 目标用户

  • 持有多账户资产（资金/现货/合约/理财/Launchpad）的普通用户 → 主要看总资产分析。
  • 活跃合约交易者 → 主要看合约盈亏分析。

1.3 名词说明

名词含义
钱包余额合约账户持有加密货币总值，钱包口径，不含未实现盈亏
未实现盈亏按标记价格计算的持仓浮动盈亏，未平仓
已实现盈亏平仓落袋的盈亏
净转入 / 净划入划入金额 − 划出金额
资金费用持仓跨结算周期按资金费率收取/支付的费用
ROE收益率，单笔仓位已实现盈亏 ÷ 初始保证金
UTC+8全站统计时区，所有「日」按 UTC+8 自然日切分

1.4 角色与权限

仅登录用户本人查看自己的数据，无多角色。假设 无子账户维度。

1.5 阅读对象

产品、设计、前端、后端、测试、数据。

2.3 全局规则

  • 时区：所有统计按 UTC+8 自然日切分；「今日」= 当日 00:00 起。
  • 数值精度：金额展示截断至 2 位小数；费率类 2 位；手续费展示原始精度（7 位）。待确认 截断 vs 四舍五入。
  • 涨跌色：绿涨 / 红跌（品牌配色，与部分竞品红涨绿跌相反，为刻意保留）。
  • 空数据：无数据周期图表显示占位，数值显示 0.00；累计盈亏率在分母为 0 等特殊情境显示 N/A。
  • 维护期：每日 0:00–4:00（UTC+8）维护期间「今日盈亏」不计算。

三、功能需求

3.1 总资产分析（P3）

用户故事：作为多账户用户，我希望按周期查看总资产走势、每日盈亏日历、累计盈亏率与资产构成，以便判断整体投资表现。

结构（从上到下）

  1. 固定头部块（不随下方时间筛选变化，仅与「今日/本月/累计」口径相关）：总资产估值 + ≈BTC 估值、今日盈亏（额+%）、本月盈亏（额+%）、累计盈亏（额+%）
  2. 时间筛选（吸顶）：7天 / 30天 / 90天 / 180天 / 自定义时间
  3. 资产走势卡：折线图 + 顶部高亮框（日期+当日估值）；拖动出现竖虚线落点，数据回填高亮框
  4. 盈亏统计卡：切换「累计盈亏 / 累计盈亏率」；累计盈亏率叠加 BTC 累计涨跌幅对比线
  5. 每日盈亏卡：日历图（默认，热力底色）/ 柱状图 双视图；点选某日高亮显示当日盈亏。本卡为固定全量数据，不随上方时间筛选变化
  6. 资产配置卡：环形图；切换「币种组成 / 资产分布」；副标题「最近更新 时间」；点击币种高亮，超过 Top10 归并「其他」

3.2 合约盈亏分析（P4）

用户故事：作为合约交易者，我希望查看合约账户的今日/本月/累计盈亏、盈亏率对比、每日盈亏日历，以及交易分析、盈亏排行和逐笔订单，以便复盘交易表现。

结构

  1. 盈亏概览卡：今日盈亏（%+USD）；本月盈亏、累计盈亏（累计下方附盈亏率）；右上角「交易额」标签，点击跳「合约分析」子 Tab
  2. 时间筛选：7日 / 近1个月 / 近3个月 / 近1年 / 自定义
  3. 主 Tab（吸顶）：总览 / 合约分析
    • 总览：盈亏统计（累计盈亏 / 累计盈亏率，率含 BTC 对比线）+ 每日盈亏（日历默认 / 柱状）
    • 合约分析：交易分析卡（见 3.2.1）→ 盈亏排行卡（按合约聚合，按盈亏额绝对值从大到小 Top5）→ 订单明细卡（见 3.2.2）
  4. 页脚：数据按 UTC+8 计算说明

  • 头部：币种·永续 + 状态（已成交绿/已取消红）；标签行（开/平多空 · 市价/限价 · 逐仓/全仓 · 杠杆）
  • 订单信息：订单编号（可复制）、订单价格、平均成交价格、订单数量、成交数量、手续费、已实现盈亏、订单时间、更新时间
  • 成交明细（仅已成交展示）：价格、数量、手续费、已实现盈亏、角色、时间

四、字段计算口径（核心）

以下公式与原型内「口径说明」完全一致，作为研发实现依据。

4.1 账户级（总资产分析）

字段计算公式口径说明
总资产估值Σ 各账户(资金/现货/合约/理财/Launchpad) 折算计价币种后的估值不含负债；随标记价格实时变化
今日盈亏当前资产 − 今日初始资产 − 今日净转入今日初始 = 当日 00:00(UTC+8) 资产；含未实现盈亏；维护期不计算
昨日盈亏昨日 24:00 资产 − 昨日 00:00 资产 − 昨日净转入含未实现盈亏
本月盈亏本月第一个自然日 00:00(UTC+8) 至当前时刻的累计盈亏—
累计盈亏（账户）当前资产 − 期初资产 − 期间净转入含已实现 + 未实现盈亏
累计盈亏率（账户）累计盈亏 ÷ (期初账户资产 + 期间转入)对比线为 BTC 累计涨跌幅；特殊情境可能为 N/A
每日盈亏（账户）指定日期账户持仓与交易活动产生的收益额盈亏月历 / 柱状双视图
资产配置·币种组成各币种折算市值 ÷ 总市值Top10 + 其他
资产配置·资产分布各账户市值 ÷ 总市值—

4.2 合约级（合约盈亏分析）

字段计算公式口径说明
钱包余额总净划入 + 总已实现盈亏 + 总净资金费用 − 总手续费钱包口径，不含未实现盈亏
今日盈亏（合约）当前资产 − 今日初始资产 − 今日净转入—
本月盈亏（合约）本月第一个自然日 00:00(UTC+8) 至当前的累计盈亏—
每日盈亏（合约）每日 24:00(UTC+8) 钱包余额 − 每日 00:00 钱包余额 − 每日资金净转入钱包口径，不含未实现盈亏
累计盈亏（合约）期末钱包余额 − 期初钱包余额 − 期间资金净转入不含未实现盈亏
累计盈亏率（合约）累计盈亏 ÷ (期初钱包余额 + 期间日均资金总转入)对比线 BTC；特殊情境 N/A
净划入当日划入合约账户总额 − 当日划出合约账户总额—
交易量每日 0:00–23:59:59(UTC+8) 成交额，按联合保证金汇率折算 USD—

4.3 交易分析卡

字段计算公式
胜率盈利仓位数 ÷ 总平仓仓位数
总盈亏比总盈利 ÷ 总亏损
总盈利期间所有已实现获利加总
总亏损期间所有已实现亏损加总（取正值）
净盈利/亏损总盈利 − 总亏损
平均盈亏(总盈利 − 总亏损) ÷ 仓位数
多空比多头仓位数 : 空头仓位数
最大收益 / 最大亏损期间单笔已实现盈亏的最大正值 / 最小负值

口径：基于已完全平仓仓位统计；平仓总盈亏含开平仓手续费与资金费用；交易机器人与跟单交易量不纳入。

字段计算公式 / 口径
ROE（仓位）已实现盈亏 ÷ 初始保证金 ≈ 价格变动% × 杠杆（多头正、空头反） 待确认 精确口径
平仓类型交易 / 强平
手续费开仓手续费 + 平仓手续费（原始精度展示）
资金费用持仓跨结算周期按资金费率收取(+)/支付(−)

五、非功能与验收

5.1 非功能需求（精简）

  • 性能：分析页首屏图表数据接口响应 待确认 < 800ms；时间筛选切换 < 500ms。
  • 数据：统计口径依赖每日 0:00(UTC+8) 快照 + 实时估值；累计类可预计算。
  • 埋点（建议）：页面 PV（总资产分析 / 合约盈亏 / 订单详情）；时间区间切换、Tab 切换、口径说明点开、订单卡点击进详情、复制订单号等事件。
  • 安全：仅本人可见；资产数值支持「眼睛」隐藏。

5.2 验收要点

  1. 切换时间区间后，走势图、盈亏统计、盈亏排行随之刷新；每日盈亏卡不随区间变化。
  2. 累计盈亏率图与 BTC 对比线均落到标注端点；分母为 0 时显示 N/A。
  3. 每日盈亏日历：默认展示日历图，点选某日高亮并回填当日盈亏；无默认选中态。
  4. 订单历史点击整卡进入订单详情；已取消订单不展示「成交明细」。
  5. 全站时区显示为 UTC+8；涨跌色为绿涨红跌。
