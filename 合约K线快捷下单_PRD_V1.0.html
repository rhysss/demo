一、概述（为什么做）

1.1 产品概述及目标

1.1.1 背景介绍

  • 当前 App 合约用户在 K 线页发现交易机会后，需返回或跳转至合约交易页填写价格、数量后才能下单，路径为「看图 → 切页 → 填单 → 提交」，共 4 步以上。短线行情瞬息变化，路径过长导致错过价位、下单转化流失。
  • 头部竞品（币安、OKX、Bybit）均已在 K 线页提供「图表交易」能力：点击图表任意价位唤起下单入口、图上直接管理持仓与委托。该能力已成为高频合约用户的使用习惯与选择交易所的因素之一。

1.1.2 产品概述

在合约 K 线页内提供一套完整的图表交易能力：

  • 快捷下单：点击 K 线图任意价位出现「＋号价格标签」，拖动微调价格，点击＋号弹出开/平仓面板，两步完成下单；
  • 图上订单管理：持仓均价线与实时盈亏标签、委托挂单线（可拖拽改价 / 撤单）、止盈止损线（可拖拽改价）、历史成交 B/S 标记；
  • 配套能力：图表设置（订单显示 / 图层显示 / 下单二次确认）、底部常驻做多/做空栏与多空比。

1.1.3 产品目标

类型目标衡量指标
业务目标提升 K 线页下单转化与合约交易频次K 线页下单占合约总下单比例、人均日下单笔数、合约交易量 待确认：基线与目标值
业务目标对齐竞品能力，减少高频用户流失高频用户（日均 ≥5 单）留存率
用户目标缩短「发现价位 → 完成下单」路径至 2 步（点图 → 点＋提交）下单路径耗时、快捷下单渗透率
用户目标不离开图表即可管理持仓与委托图上改价/撤单/平仓操作占比

1.1.4 目标用户

  • 核心：已开通合约的高频短线交易用户（依赖 K 线做决策、对下单时效敏感）；
  • 次要：全体合约用户（图上持仓/委托可视化对所有人可用）。

二、产品描述（做什么）

2.1 产品需求描述

在合约 K 线页集成图表交易：用户开启快捷下单后，点击图表任意价位出现＋号价格标签，拖动定价、点击＋号弹出开/平仓面板提交订单；已产生的持仓、委托、止盈止损以水平线 + 标签形式实时呈现在图上，支持拖拽改价、一键撤单、反手、平仓；配套图表设置控制各类图层与订单元素显隐；底部提供常驻做多/做空快捷入口与多空比。

三、功能需求（怎么做）

3.1 快捷下单入口与＋号价格标签

用户故事：作为高频合约交易者，我希望在 K 线上点一下想要的价位就能得到一个可微调的下单入口，以便不切页、不手输价格地完成挂单。

前置条件：已登录、已开通合约、快捷下单开关开启（默认开启 假设）。
后置条件：产生一笔委托或成交；＋号标签收起。

3.1.1 界面与交互

元素规则
开关入口图表设置面板「快捷下单」勾选项为唯一开关入口（默认开启 假设）；关闭时收起已唤起的标签且单击不再唤起
＋号价格标签黑色圆角标签，吸附价格轴左侧；左段：白色圆形＋按钮（独立点击区，带竖分隔线与按压反馈）；右段：价格（tick 取整）+ 距最新价百分比（≥0 绿 / <0 红），随行情每 tick 重算
引导虚线标签所在价位横贯图表的灰色虚线，随拖动实时移动
唤起单击图表（价格轴区域除外）在点击价位唤起；已唤起时单击其它价位 → 标签移动至新价位
拖动按住标签任意区域上下拖动改价，跟手刷新价格/百分比/虚线；命中判定 ±14px
收起①单击标签当前价位 ±14px 内；②提交订单成功后；③关闭快捷下单开关；④标签价位超出可视区时隐藏（回到可视区恢复）
点击＋号弹出开/平仓面板（3.2），价格输入框预填标签价位；仅＋号段触发，价格段点击不触发

3.1.2 异常/分支

  • 快捷下单关闭时：单击图表走十字光标逻辑，不出现标签；
  • 十字光标显示中：单击优先关闭光标，第二次单击才唤起标签；
  • 横向拖动（平移K线）不唤起标签（位移 >5px 判定）。

3.2 开/平仓面板

用户故事：作为用户，我点击＋号后希望在一个面板里完成方向、价格、数量的确认并直接提交，以便两步内完成下单。

前置条件：＋号标签已唤起并点击＋。
后置条件：产生委托/成交，面板关闭，标签收起。

3.2.1 界面与交互

区块元素与规则
头部合约名 + 永续标签 + 实时最新价/涨跌幅（红绿着色）；右侧芯片：保证金模式（全仓/逐仓）、杠杆倍数（点击进入杠杆调整弹层）
开仓/平仓 Tab分段控件；切「平仓」：下单按钮变「平空·买入（绿）/平多·卖出（红）」，数量预填当前持仓量，滑杆基数切换为持仓量
价格框内嵌「价格」小标签 + USDT 单位；预填＋号标签价位；可编辑，按 tickSize 校验
市价按钮价格框右侧独立按钮；开启后价格框置灰禁用、按市价成交；再点关闭恢复限价
数量框单位下拉支持三种录入单位：数量（BTC）、成本（USDT，= 数量 × 价格 ÷ 杠杆）、价值（USDT，= 数量 × 价格）；切换单位时按当前价格与杠杆将已填值自动换算回显；占位符与单位标识随切换更新；提交时统一折算为数量（BTC）下单，按 stepSize 校验
仓位%滑杆菱形滑块 + 0/25/50/75/100% 刻度；开仓：数量 = 可开 × 百分比；平仓：数量 = 持仓量 × 百分比
资金信息可用（含划转入口⇄）；双列「可开 / 保证金」（多、空各一列）；随价格/数量实时重算：可开 = 可用 × 杠杆 ÷ 价格；保证金 = 数量 × 价格 ÷ 杠杆
下单按钮开多·看涨（绿）/ 开空·看跌（红）大圆角按钮；提交后 loading 防连点
底部链接「前往合约交易页 ›」跳转完整交易页

3.2.2 下单规则

  • 市价开启 或 限价发生价格穿越（买价 ≥ 最新价 / 卖价 ≤ 最新价）：按市价立即成交；
  • 否则：挂出限价单，图上生成委托线，＋号标签收起；
  • 平仓：按所选方向校验持仓存在；数量 > 持仓量时截断；成交后 Toast 展示已实现盈亏；
  • 面板本身视为一次确认，不再叠加「下单二次确认」弹窗（二次确认仅作用于底部做多/做空栏）。

3.3 持仓线与盈亏标签

用户故事：作为持仓用户，我希望在图上直接看到开仓均价与实时盈亏，并能就地止盈止损、反手、平仓。

元素规则
持仓均价线方向色虚线（多绿/空红），价格轴挂对应价签；由设置项「仓位」控制显隐
盈亏标签线左侧：方向+持仓量、未实现盈亏与 ROE%（红绿着色），随行情每 tick 刷新；快捷按钮：TP/SL（打开止盈止损弹层）、反手、平
反手市价平掉当前仓位并立即以同数量反向市价开仓；两笔独立记账，Toast 逐笔反馈
平弹出市价平仓确认（持仓、均价、预计盈亏）→ 确认后全部市价平仓

3.4 委托挂单线

行为规则
展示每笔未成交限价单一条方向色点线；标签：⠿ 限价买/卖 + 数量 + @价格 + ✕；设置项「当前委托」控制显隐
拖拽改价「K线改单」开启时，按住标签纵向拖动，松手提交改价（语义 = 撤旧挂新，重新排队），Toast「委托价已修改，重新排队」；tick 取整
撤单点 ✕ 立即撤单（无需确认 假设）；列表页「一键撤单」同步清空
成交行情触达委托价（买：最新价 ≤ 委托价；卖：最新价 ≥ 委托价）即成交：委托线消失、生成/合并持仓、K线打 B/S 标记、Toast 成交回报

3.5 止盈止损（TP/SL）

行为规则
设置入口持仓标签 TP/SL 按钮或持仓卡片「止盈/止损」
设置弹层止盈价、止损价（均选填）；实时计算预计盈亏；方向校验：多仓止盈须 > 最新价、止损须 < 最新价（空仓反之），不通过则拦截提示
图上呈现止盈绿色长虚线、止损红色长虚线 + 可拖拽标签（受「K线改单」开关控制）+ ✕ 撤销
触发最新价触达 → 全仓市价平仓（触发即市价 假设：V1.0 仅支持市价触发、全部平仓）；成交后 Toast + 记入历史

3.6 B/S 成交标记

每笔成交（开、平、止盈止损触发、反手）在成交时刻对应 K 线打标：买入 = K线下方绿色向上三角 + B；卖出 = K线上方红色向下三角 + S。由设置项「历史委托」控制显隐。同根 K 线多笔成交时标记堆叠展示 待确认：堆叠上限与聚合规则。

四、非功能需求

4.1 安全与合规

  • 下单/改价/撤单全部走现有合约订单接口鉴权与风控链路（限频、自成交防护、价格偏离保护）；
  • 防误触：单击判定阈值（位移 ≤5px 且 ≤450ms）、＋号独立点击区、提交按钮防连点去重；
  • 快捷路径不豁免任何风控规则；风控拦截文案与交易页一致。

4.3 性能需求

  • 标签/线拖拽跟手渲染 ≥ 30fps，行情 tick 到图上 PnL 刷新 ≤ 500ms 待确认；
  • 下单接口端到端 P99 ≤ 300ms（不含撮合回报）待确认；
  • 图上订单元素（线+标签）同屏 ≤ 20 个时无掉帧；超出按距最新价排序截断展示 待确认：截断策略。

4.4 数据与存储

  • 无新增服务端存储：订单/持仓/成交复用现有合约域接口与推送；
  • 图表设置项本地持久化（KV），key 规范 kline_chart_setting_*；
  • 下单来源 source 字段落订单表，用于渠道转化分析。
