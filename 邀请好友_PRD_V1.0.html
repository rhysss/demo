产品需求文档 PRD V1.0
文档版本 V1.0日期 2026-11-24需求规模 M 级（跳过竞品调研）规则依据 规则台账_邀请好友 v0.6原型 1124-邀请好友-原型.html涉及端 App（Web、H5 见待确认 Q18）

1. 需求分析

1.1 背景

一个用户身上同时存在两套邀请关系，但 App「邀请好友」页只展示其中一套：

关系怎么建立覆盖业务能否修改现在的邀请页
交易所邀请关系注册交易所账户时填写邀请码现货、合约等⚠️ 注册后能否补填待确认（Q1）展示
美股通邀请关系注册后在美股通另外绑定；注册交易所时不会自动绑定跟单、跟盈宝绑定后不能修改或解绑不展示（美股通有自己的邀请记录页）

两套关系的邀请码完全相同，区别只在邀请链接的前缀。没有绑定美股通关系时，跟单、跟盈宝不产生邀请返佣。

因此同一个好友可能有两个不同的上级，例如：A 的交易所上级是 B，美股通上级是 C。这是现有设计下的正常情况。

1.2 问题

编号现象原因
问题 1好友交易过，邀请页却一直显示「未交易」好友只做了跟单或跟盈宝，这些成交属于美股通关系；页面没有说明交易状态的统计范围
问题 2邀请人在邀请页找不到自己邀请的人好友是在美股通绑定的，邀请页只展示交易所关系
问题 3邀请人对“好友到底算谁的”有疑问两套关系的上级可以不同，页面没有把两套关系分开说明

1.3 用户分析

用户诉求本期如何满足
普通邀请人知道邀请了谁、谁交易了，判断返佣从哪来两套关系分 Tab 展示，交易状态按返佣归属统计
主推跟单、跟盈宝的邀请人看到自己在美股通的直推新增美股通 Tab，并能直接复制或分享美股通链接
受限地区用户不能使用美股通，不应看到相关入口隐藏美股通链接和美股通 Tab，页面保持现状

1.5 目标

  • 邀请人在一个页面看全两套关系下的直推好友
  • 页面展示的交易状态和返佣归属一致，不再引起误解
  • 衡量指标：邀请页相关客诉量、美股通链接的复制和分享次数（⚠️ 目标值待确认）

2. 产品概述

2.1 产品逻辑

关系建立流程

步骤交易所邀请关系美股通邀请关系
1. 邀请人分享在邀请页复制或分享「交易所链接」在邀请页复制或分享「美股通链接」
2. 好友打开链接进入交易所注册页，邀请码自动带入进入美股通绑定流程（⚠️ 好友还没有交易所账户时的流程待确认，Q11）
3. 建立关系好友注册成功，邀请人成为好友的交易所上级好友绑定成功，邀请人成为好友的美股通上级；绑定后不能修改
4. 邀请人看到交易所 Tab 新增一条，显示注册时间美股通 Tab 新增一条，显示绑定时间

好友在列表中的状态

Tab状态进入条件说明
交易所未交易好友注册成功只统计现货、合约；闪兑、杠杆、跟单、跟盈宝的成交都不算
交易所已交易好友有过现货或合约成交⚠️ 是否不会退回未交易，待确认（Q19）
美股通未交易好友在美股通绑定成功只统计跟单、跟盈宝；现货、合约的成交不算
美股通已交易好友有过跟单或跟盈宝成交⚠️ 同上（Q19）

两个 Tab 的交易状态更新时效一致，沿用现有邀请页的时效（⚠️ 具体时效待提供，Q15）。

2.3 术语解释

术语解释
交易所邀请关系好友注册交易所账户时用邀请码建立的关系，决定现货、合约等业务的返佣归属
美股通邀请关系好友在美股通绑定邀请码建立的关系，决定跟单、跟盈宝的返佣归属；绑定后不能修改
交易所上级 / 美股通上级好友在两套关系中各自的邀请人，可以是同一个人，也可以不同
直推直接邀请的好友；本期不展示好友再邀请来的下级
交易所链接 / 美股通链接邀请码相同、前缀不同的两条邀请链接，好友打开哪条就建立哪套关系
美股通邀请人门槛当美股通邀请人需要满足的条件，例如开通美股通或完成 KYC（⚠️ 是否存在待确认，Q14）

2.4 重要信息 Checklist

类别结论
资金本期只改展示，不改任何返佣规则和返佣归属
合规受限地区、不能使用美股通的用户，隐藏美股通链接和美股通 Tab
隐私只展示自己的直推；不展示好友在另一套关系里的上级是谁；好友账号的脱敏方式沿用现有邀请页
历史数据美股通 Tab 展示用户上线前已经绑定的全部美股通直推，不需要用户做任何操作
多端如果 Web、H5 也有邀请页，各端一起改（⚠️ 是否存在待确认，Q18）

2.5 上线节奏

阶段内容
本期邀请区双链接、链接选择弹层、我的推荐分两个 Tab、完整列表分两个 Tab、受限地区和门槛的展示差异
后续评估在交易所 Tab 提示好友去绑定美股通（方案 F）：等本期上线、看到数据后再评估
美股通团队评估好友在美股通绑定时，默认带出他的交易所上级（方案 E）

3.2 页面交互流程

  • 用户进入邀请好友页 → 系统判断用户类型（普通 / 受限地区 / 未满足美股通门槛）→ 展示对应的邀请区和我的推荐
  • 复制：点推荐码或任一链接右侧的复制图标 → 提示「已复制」
  • 立即邀请：普通用户 → 弹出链接选择 → 选一条 → 打开系统分享；受限地区用户 → 直接打开系统分享（交易所链接）
  • 切换 Tab：点「交易所」或「美股通」→ 列表、说明文案、「总推荐」人数切换为该 Tab 的数据
  • 查看全部：点「总推荐 ›」→ 进入完整列表页，停在当前 Tab → 返回后邀请页停在用户最后所在的 Tab
  • 加载失败：失败的 Tab 显示「加载失败，请稍后重试」和「重试」按钮，Tab 上人数显示「--」；点重试只重新加载这个 Tab
