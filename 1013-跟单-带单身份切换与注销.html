改动说明

  1. 新增跟单模块合并为一页：发现 / 我的跟单 / 带单中心 / 带单交易。原来成为带单员后「交易员主页」直接替换了跟单页，回不去；现在带单员多出「带单中心」「带单交易」两个 Tab，其余不变，随时切换。
  2. 新增带单员不能跟单：带单员在发现页、项目详情看到的「跟单」按钮置灰，点击提示「注销带单员后可跟单」；「我的跟单」仍可查看账户和历史。
  3. 新增每个项目独立余额：带单账户 = 未分配余额 + 各项目余额。新建项目时从未分配余额划入项目资金；带单交易只用当前项目余额；「调整余额」在项目和未分配余额之间互转；结束项目后项目余额转回带单账户。
  4. 新增「带单交易」Tab：顶部显示当前项目可用余额和「调整余额」；有多个进行中项目时可切换；没有进行中项目时引导新建；注销处理中不能下单。带单中心的「去带单」直接跳到这个 Tab。
  5. 新增注销带单员：入口在带单中心右上角「···」。流程：前置检查 → 影响告知 + 勾选确认 → 二次确认弹窗 → 结果页。必须先手动结束全部项目；有待结算分润时进入「处理中」，本期结算后生效，期间可撤回；生效后带单账户余额转入跟单账户；7 天内不能重新申请，重新申请后战绩继承。
  6. 优化发现页卡片：补带单员头像 + 名称、收益率 + 收益额 + 收益曲线；跟单人数显示「当前 / 500」，满员显示「已满员」；运行不足 7 天收益率显示「--」。自己的项目标「我的」，按钮为「管理」。
  7. 优化带单中心：项目卡片显示项目余额，补「去带单 / 结束项目」；「+ 新建项目」移到项目 Tab 栏右侧；去掉搜索按钮。
  8. 优化统一叫法：带单侧「项目」与跟单侧「带单策略」统一为「项目」，跟单侧「我的项目」改为「我的跟单」。
