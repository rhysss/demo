改动说明

  1. 新增跟单模块合并为一页、三个 Tab：发现 / 我的跟单 / 带单中心。原来成为带单员后「交易员主页」直接替换了跟单页，回不去；现在带单员多出一个「带单中心」Tab，其余两个 Tab 不变，随时切换。
  2. 新增注销带单员：入口放在带单中心右上角「···」里（低频、不可逆操作，不放主按钮位）。流程：前置检查 → 影响告知 + 勾选确认 → 二次确认弹窗 → 结果页。
  3. 新增区分「结束项目」和「注销身份」：结束项目是单个项目级，沿用现有流程；注销是身份级，要求先结束所有进行中项目，避免重新定义跟随者仓位的处理规则。
  4. 新增注销处理中状态：有待结算分润时，提交后进入「处理中」，等本期分润结算完再生效；处理中可撤回，不能新建项目。
  5. 优化发现页卡片：补上带单员身份（头像 + 名称），收益率 + 收益额 + 收益曲线；跟单人数显示「当前 / 上限」；运行天数不足时收益率显示「--」，不显示 0.00% 误导用户。
  6. 优化带单员自己的项目出现在发现页时标「我的」，按钮从「跟单」换成「管理」，防止自己跟自己。
  7. 优化带单中心补快捷入口：跟单用户 / 分润明细 / 余额历史 / 我的主页（对标竞品「交易专家中心」）；进行中项目卡片补「去带单 / 结束项目」操作；「+ 新建项目」从底部按钮移到项目 Tab 栏右侧；空状态补引导文案。
  8. 交互全部入口可点：带单交易（下单 / 平仓）、新建项目、跟单 / 停止跟单、项目详情、我的主页、跟单用户、分润明细、余额历史、账户划入划出、编辑资料、搜索、带单规则、申请成为带单员，数据联动。
  9. 优化统一叫法：带单员侧叫「项目」，跟单侧叫「带单策略」，原来同一个东西两种叫法。原型统一为「项目」，跟单侧「我的项目」改为「我的跟单」。
  10. 优化普通用户的「成为带单员」入口放在发现页顶部横幅；注销后冷却期内横幅变为置灰提示。
