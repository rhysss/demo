黄金交易对指标竞品调研

各家交易所的黄金交易对给了哪些指标？有没有专门为黄金设计的指标？
调研日期 2026-11-21 · 范围：Binance / Bitget / Bybit / OKX / Gate / Hyperliquid，补充传统券商与 TradingView · 只看了 Web 端

结论

  1. 没找到任何一家加密交易所给黄金单独做指标。黄金永续直接复用加密合约那套 K 线：TradingView 图表加自研简版图表，指标列表和 BTC 一样。
  2. 各家为黄金做的差异化都不在指标上，而在交易时段：价格旁标「非交易时段」、展示开收盘时间、休市期间的标记价格规则。做黄金 CFD 的几家（Bybit、Bitget、Gate）走 MT5，用的是 MT5 自带指标。
  3. 真正为黄金设计的工具，在传统券商和 TradingView 社区：金银比、交易时段框、CFTC 持仓报告、客户多空情绪、经济日历。

对方案的影响：「黄金专属指标」在加密交易所里没有可直接参考的做法。如果做，就是差异化，但口径需要我们自己定义。

三、调研局限

  • Binance、OKX 的交易页在调研环境里打不开，Bybit 交易页加载不出数据，这三家的图表细节来自帮助中心、公告和新闻报道。
  • 只看了 Web 端，App 端没有核实。
  • Bitget 只核实了 TradingView 工具栏和数据页，没有逐个点开指标列表。
  • 券商部分的来源有不少是比价站和券商自己的营销内容，功能有没有、叫什么名字，以各家官网为准。
