OTC 快捷买币（Quick Buy · Buy）全流程交互原型

左侧手机可完整走通：买币下单 → 报价确认 → 付款页（商家收款账户 / 15分钟倒计时 / 我已付款）→ 已支付待放行 → 商家放币完成，以及 历史订单 / 订单详情五态 / 超时取消 / 申诉。合作方 ChipPay。
设计口径（与卖币镜像、与后台一致）：支付 Pay（CNY）= 购买数量 × 单价；到账数量 Receive（USDT）= 购买数量 − 手续费（手续费从买到的币中扣）。状态流：待支付 → 已支付待放行 → 已完成（可分支 已取消 / 申诉中）。买币需线下向商家转账，故新增「付款页」，且下单不走二次验证（无平台资金流出，风险点在放币环节由商家控制）。⚠️ 手续费=数量×1%、单价 7.35 均为演示值，待你确认。
