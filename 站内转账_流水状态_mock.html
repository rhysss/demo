流水状态展示 + 对账口径

模型：所有内转都需审核。三态——审核中 / 成功（通过）/ 失败（拒绝），加收款方的转入。一笔转账永远只占一条流水，靠状态样式表达，不用 ±抵消。
🕐 审核中
付款 −；金额半透明弱化 + 「冻结中」标。对账：只冻结（可用 −284，总额不变）。
✅ 成功
审核通过、已转出；− 绿正常 +「成功」。对账：实扣（总额 −284）。收款方此刻才出现「转入」。
❌ 失败
审核拒绝；金额置灰 + 删除线 +「已退回」。对账：作废按 0（冻结释放、钱退回），不生成 +284 退回条。
＋ 转入
收款方视角，+ 粉；仅在审核通过后出现（钱没到不显示）。

对账示例（付款方 · 期初 可用 1000 / 冻结 0）

流水状态金额计入总额计入冻结
A成功−284−2840
B审核中−2840+284
C失败−28400
结果：总额 = 1000 − 284(仅 A) = 716；冻结 = 284(仅 B) = 284；可用 = 总额 − 冻结 = 432。
三者恒等：总额 = 可用 + 冻结 ✓，且每笔只一条，无冗余抵消。
对账一句话口径（务必同步研发）：
流水金额 = 转账方向金额（固定 −），≠ 该条一定改变余额。是否改余额由状态决定：成功→减总额；审核中→只占冻结；失败→按 0（退回）。求「总额变化」只累加成功笔即可平账，无需 −284/+284 抵消条目。
